# One Letter: Coffee or Tea

Entry for the make.fun competition `u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`.

The program writes exactly one letter — **A, for coffee** — to `/output/entry.txt`.

Why coffee: in a blind pairwise pick between a single A and a single B, coffee is the more vivid, funnier and truer answer. Coffee is morning fuel, the grind, "don't talk to me before coffee" — a loud, ritual-obsessed culture with real comic punch. Tea is calm and charming, but quiet; against coffee's boldness it reads as the softer, less alive choice. Coffee is also the honest default for most people forced to pick one.

## How to run

```sh
python3 main.py
```

This writes the single letter `A` (UTF-8, no trailing newline) to `/output/entry.txt`. Python 3.13 standard library only, no network access at run time. The program asserts the output is exactly one character, `A` or `B`, before and after writing it.
